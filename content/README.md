# Editorial content

Since PR5b the live site reads each page's text from the dashboard (**Pages**, stored in Supabase `page_texts`). The page files here (all but `reminders.yaml`) are only the local sandbox's starter text and the source of the one-time seed (`scripts/page-text-seed.mjs`): editing them does not change the live site, except the developer-owned parts (the menu, header button, footer, logo and search keywords in `site.yaml`, the term filters in `events.yaml`, the categories in `resources.yaml`; `developerOwnedPaths`), which the site always reads from here. Season pages (Ramadan's included) and the merch collections, items, photos and sizes are dashboard data since PR5c (**Seasons**, **Merch**): no file here holds them; `merch.yaml` is only the Merch page's opening. `reminders.yaml` keeps the dhikr of the hour and the tasbih, a fixed developer-owned list. Qur'an verses are not in these files: each place's verse is picked by the board in **Pages → Qur'an verses** from the fixed verse library in `quran_verses` (built once from `src/lib/quran/verse-library.json`; `reminder-places.yaml` holds the starter picks; [ADR 0026](../docs/adr/0026-fixed-quran-verse-library.md)).

This folder contains infrequently changing site copy. Changing live events, announcements, news, newsletters or prayer/iqamah schedules here does **not** update their database-backed public records.

Board members should use the [Board Handbook](../handover/SGU-MSA-Website-Handbook.docx). Developers should use the [developer guide](../docs/guides/developer.md) for schemas, validation and approved editorial changes.
