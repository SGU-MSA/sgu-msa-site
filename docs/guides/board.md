# Board member guide

Everything a board member needs is in one Word file: the **[SGU MSA Website Handbook](../../handover/SGU-MSA-Website-Handbook.docx)** (`handover/SGU-MSA-Website-Handbook.docx`). It covers who can do what, everyday tasks, money (Go2Pay), sign-up forms, a new board term, and accounts and emergencies.

- The board owns the handbook and edits it in Word or Google Docs. Their own notes go in its last chapter. Export a PDF only to print; never keep a second copy.
- On the dashboard, the **Show me how** button beside **Sign out** walks you through the screen you are on.
- Developers: technical setup stays in the [owner setup guide](owner-setup.md). When a dashboard screen changes, update the handbook's steps in the same pull request (or list them under "Handbook notes" in the PR body).
